لینک‌های نسبی `.agents/skills/` به نسخه‌های داخل همین مخزن اشاره می‌کنند؛ کپی تکراری یا نصب جهانی لازم نیست. شناسهٔ اسکیل اول از نام تکراری `maalsadiqeen-reel` به `maalsadiqeen-1` اصلاح شده است. اسکریپت نصب تکرارپذیر است و هیچ اسکیل نامرتبطی را بازنویسی نمی‌کند.

## بازتولید

پیش‌نیاز: Linux x86_64، Node 22.12+، Python 3.11+ با venv، tar.

```sh
bash scripts/setup.sh        # npm ci + Python wheels + مرورگر و FFmpeg محلی
npm test                    # تست‌های محتوا، اسکیل، زمان‌بندی و سازگاری
npm run reel:build           # content/spec → HTML + صوت
npm run reel:check           # بررسی مرورگر + فریم‌های QC
# ابتدا work/ashab-51/project/qc/sheet.jpg را بررسی کنید.
npm run reel:render          # رندر یک‌پردازشی + بررسی فایل + کاور و بیت‌شیت
npm run preview             # پیش‌نمایش فایل نهایی روی 0.0.0.0:3000
```

دریافت وابستگی‌ها فقط از npm و PyPI انجام می‌شود. باینری Chromium و کتابخانه‌های موردنیاز از بستهٔ پین‌شدهٔ npm استخراج می‌شوند؛ نیازی به دانلود از میزبان Chrome، apt یا کلید API نیست. FFmpeg از wheel بستهٔ `imageio-ffmpeg` می‌آید. Pillow بدون RAQM نیز با fallback دقیق HarfBuzz قابل‌استفاده است.

سرور پیش‌نمایش فقط فایل‌های مشخص‌شدهٔ خروجی را ارائه می‌کند؛ به `.git` و سایر فایل‌های مخزن دسترسی نمی‌دهد. ویدیو و منابع داخل پیش‌نمایش با URL نسبی بارگذاری می‌شوند.

## کنترل کیفیت و اصلاحات سازگاری

- بررسی متن منتخب در برابر محتوای ورق‌ها، محدودکردن نتیجه به روایت اول، منع مهر تأیید، حفظ «عند آخرين».
- بررسی پیوستگی صحنه‌ها، تعداد کلمات/کیوها، زمان CTA، عدم افزودن صدای گوینده یا تلاوتِ درخواست‌نشده.
- اصلاح f-stringهای ناسازگار با Python 3.11 در builder و دو ابزار post-kit.
- کارت‌های دوخطی اختیاری برای نام/توضیح راوی، بدون رنگ و نماد تأیید.
- رندر تنها پس از موفقیت واقعی check؛ خطای فرمان با grep یا اجرای دوباره پنهان نمی‌شود.
- کنترل نهایی: ابعاد، زمان، FPS، AAC، بلندی صوت، قله، تطبیق فریم رندر با پیش‌نمایش.

صدا: بستر سینتزشدهٔ آرام، بدون ضرب و گوینده؛ افکت‌ها از دارایی‌های موجود در اسکیل، با [سوابق مجوز مخزن](maalsadiqeen-reel/assets/sfx/CREDITS.md). هیچ رسانهٔ تازه‌ای از شبکهٔ اجتماعی دانلود نشده است. طراحی برای نگهداشت، خوانایی و اشتراک‌گذاری است؛ تضمین وایرال‌شدن نیست.
